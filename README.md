
# DevTool Hub - 开发者工具导航

# 🎨 作品集/开发者工具导航网站

## 项目概述

这是一个精美的开发者工具导航网站，集合了常用的开发工具资源，帮助开发者快速访问各类实用工具。网站采用现代化的设计风格，具有流畅的动画效果和优秀的用户体验。

## ✨ 特性

- 🌟 现代化玻璃拟态设计
- 🎭 流畅的微交互动画
- 📱 完全响应式布局
- 🔍 实时搜索功能
- 🏷️ 分类筛选功能
- ⚡ 轻量快速（纯前端）

## 🛠️ 技术栈

- HTML5
- CSS3（Flexbox + Grid + 变量）
- Vanilla JavaScript
- jQuery
- Google Fonts

## 📦 部署

### Cloudflare Pages

1. 将项目推送到 GitHub 仓库
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)
3. 进入 Pages → 创建项目 → 连接 GitHub
4. 选择仓库并部署

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/YOUR_USERNAME/devtool-hub.git
cd devtool-hub

# 直接用浏览器打开 index.html
```
